No daily boosted values

Players can select 10 battles each day to receive boosted values. Each battle can be boosted to ×3 values. Before each battle, player can view all the waves and toggle whether the boost should apply.

A formation with the challenge wave can be worth almost 30,000 points.

Formation Rework

Every wave is drawn, not scripted. A formation used to be one of ten fixed battles, played from start to finish. Now, it is built wave by wave, so wave 2 of one battle can follow wave 1 of another.

×4Waves 1 to 4 are each drawn from all 10 battles' matching wave, independently and uniformly.
10%Chance of a fifth, challenge wave appeared after wave 4. Only 1 challenge wave in Battle 10 to sample from.

The pool

Click any wave to pick it for that slot. Dimmed waves were not drawn.
