# Boss Strike Rework infographic

Infographic for the Boss Strike 3 (Legacy BS 15) Infected formation rework.

- `index.html`: self-contained interactive page (images embedded). Open it in a browser. This is also the page GitHub Pages serves.
- `boss_strike_wave_draw.png`: static image for sharing on Discord.
- `source/`: editable page (`wave-draw.html`) and the wiki images it loads from `img/`.

Formations and point values come from the Battle Nations Mirahaze wiki.
